Compatibility Rules Matrix

Shows whether cleaning is required when switching between load types, with cost and duration

How to Read
  • Row = what the truck previously carried (FROM)
  • Column = what it needs to carry next (TO)
  • ✓ ₹Cost / Minutes = cleaning required with that cost and time
  • No = no cleaning needed, truck goes straight to the gate
  • — = same load type, no transition
